## Опис

Це консольний парсер для мережі Аврора, який дозволяє:
- Шукати магазини по місту
- Вибирати магазин для подальшої роботи
- Шукати товари по баркоду
- Перевіряти всі знижки у магазині (у кілька потоків)
- Фільтрувати товари по категоріях KT
- Враховувати статус "тільки на сайті" та "знятий з продажу"
- Зберігати налаштування у config.json

## Встановлення

1. Встановіть Python 3.9+
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Встановіть Tesseract-OCR (для розпізнавання зображень):
   - [Завантажити для Windows](https://github.com/tesseract-ocr/tesseract/releases)
   - Додайте шлях до tesseract.exe у PATH
   - Перевірте: `tesseract --version`
4. Встановіть Playwright браузери:
   ```bash
   playwright install
   ```

## Запуск

```bash
run.bat
```

## Основні можливості

- **Меню налаштувань:**
  - Перемикання виводу повідомлень про зняті з продажу товари
  - Зміна магазину (місто, адреса)
  - Зміна KT-фільтра (all або список через кому)
- **Пошук по баркоду**
- **Масовий пошук знижок** (режим 3 — повільно, режим 4 — швидко, 15 потоків)
- **Фільтрація по KT**
- **Автоматичне ігнорування товарів "тільки на сайті" та "знятих з продажу"**

## Формат config.json

```json
{
  "city": "",
  "shop_number": "",
  "shop_name": "",
  "show_removed_message": false,
  "kt_filter": "all"
}
```

- `city` — місто для пошуку магазину
- `shop_number` — ID магазину
- `shop_name` — адреса магазину
- `show_removed_message` — чи виводити повідомлення про зняті з продажу товари
- `kt_filter` — all або список KT через кому (наприклад, "2,3,4")
