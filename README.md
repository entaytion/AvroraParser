## Опис

Два інструменти для роботи з мережею Аврора:

### `avrora_parser.py` — CLI-парсер знижок
- Пошук магазинів по місту
- Пошук товарів по баркоду з інфо про знижки
- Async-сканер всіх знижок (15 потоків, 150к баркодів)
- Фільтрація по категоріях KT
- Перевірка статусу "тільки на сайті" через selectolax
- Збереження налаштувань у `config.json`

### `dumper_avrora.py` — автоматичний синк цін у PostgreSQL (Neon)
- Інкрементальний дамп 150к баркодів у Neon DB
- Автоматична компресія фото товарів у WebP 100×100 мініатюри
- Адаптивний rate limiting
- Запуск через GitHub Actions щоночі (23:00 Київ)

## Встановлення

Проєкт використовує [uv](https://docs.astral.sh/uv/) для керування залежностями.

```bash
# Встановити uv (якщо ще немає)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Синхронізувати залежності
uv sync
```

### Залежності

| Пакет | Для чого |
|-------|----------|
| `requests` | HTTP-запити (sync) |
| `aiohttp` | HTTP-запити (async, для масового сканування) |
| `selectolax` | Блискавичний HTML-парсинг (замість Playwright) |
| `psycopg2-binary` | PostgreSQL для dumper |
| `python-dotenv` | Завантаження `.env` змінних |
| `pillow` | Компресія фото товарів у WebP мініатюри |

## Запуск

```bash
# Парсер знижок
uv run avrora_parser.py

# Дампер цін у Neon DB
uv run dumper_avrora.py
```

## GitHub Actions

Дампер автоматично запускається щоночі через GitHub Actions workflow. Для налаштування:

1. Додайте секрет `DATABASE_URL` у Settings → Secrets → Actions
2. Workflow файл: `.github/workflows/avrora_sync.yml`

CREATE TABLE products (
